Event planning & booking system

Event Planner (C++ Project), This program allows users to plan and book events by selecting event type, venue and additional services, and automatically calculating the total cost.

  Features:
- Client registration
- Event selection
- Venue booking
- Catering service
- Decoration service
- Entertainment service
- Photography service
- Total bill calculation

  
 Files Included:
- .h files
- .cpp files
- main.cpp
- CMakeLists.txt
- OOP project slides.pdf (project presentation)
